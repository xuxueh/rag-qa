## 1. 健康检查（冷启动，检索器还没构建）

```json
GET /health → 200
{
  "status": "degraded",
  "retriever_ready": false,
  "documents": 12,
  "chunks": 0,
  "config_issues": [],
  "config": {"knowledge_dir": "...\\rag-qa\\知识库", "llm": {"api_key_set": true},
             "chunk": {"size": 200, "overlap": 20},
             "retrieval": {"recall_top_k": 10, "rerank_top_n": 3, "rrf_k": 60}}
}
```

要点：`status=degraded` + `retriever_ready=false` 是**正常的**——索引是懒加载的，第一次提问才构建。
`config_issues: []` 表示配置自检通过。

## 2. 四类问题的真实回答

| # | 问题 | 类型 | 总耗时 | 检索/生成 | 结果 |
|---|---|---|---|---|---|
| 1 | 婚假有几天？ | 普通事实 | 77.5 s（冷启动） | 10.8 s / 0.8 s | ✅ 15 天，引用 03·第五条 |
| 2 | 报销金额超过5000元需要谁审批？ | 数字/金额 | 7.3 s | 6.4 s / 0.9 s | ✅ 总经理，引用 02·第三条 |
| 3 | 出差期间的餐饮补贴按什么计算？ | 相似条款 | 7.8 s | 6.4 s / 1.5 s | ✅ 同时引用 06·第四条 与 02·第六条 |
| 4 | 公司年会在什么时候举办？ | 无答案 | 7.2 s | 6.1 s / 1.1 s | ✅ "不知道"（未编造） |

第 1 条 77.5 s 是**冷启动**：首次请求要加载 reranker（约 10 s）+ 首次构建索引；之后每次 5-8 s，
其中约 6 s 花在 CPU 精排上（与评测报告的 6111 ms 一致）。

### 问题 1 原始答案

```
依据：03-请假管理制度.txt 第五条。
结论：婚假为 15 天。
引用1：03-请假管理制度.txt · 第五条、第六条、第七条
引用2：03-请假管理制度.txt · 第一条、第二条
```

### 问题 3 原始答案（体现"相似条款 + 多来源"）

```
依据：资料中《06-差旅管理制度.txt》第四条和《02-费用报销制度.txt》第六条均涉及餐饮补贴。
结论：出差期间的餐饮补贴按每天100元、按出差天数计算，无需发票，随工资发放
     （06制度表述为"随工资发放"，02制度表述为"随当月工资一并发放"）。
引用：
- 《06-差旅管理制度.txt》第四条："出差餐饮补贴每天 100 元，按出差天数计算，无需发票，随工资发放…"
- 《02-费用报销制度.txt》第六条："餐饮补贴标准为每天 100 元，按出差天数计算，无需发票，随当月工资一并发放…"
补充核对：《06-差旅管理制度.txt》第八条还提到"驻外期间按当地生活成本适当上调餐饮补贴标准"…
```

这正是评测报告里"相似条款辨析"类问题要验证的能力：两份制度写法不同、答案一致，模型**并列引用**
而不是只挑一个，还额外指出第八条的例外情形。

## 3. 上传 → 重建 → 提问 → 删除（完整生命周期）

```json
POST /documents/upload（上传 99-演示用培训制度.txt）→ 200，耗时 17.5 s
{"ok": true, "uploaded": "13-员工培训管理制度.txt",
 "chunks": 48, "documents": 13, "elapsed_s": 17.5, "file_errors": [], "note": "检索器已重建"}

POST /ask「员工每年要参加多少小时培训？培训费用谁承担？」→ 200
依据：13-员工培训管理制度.txt 第一条。
结论：公司每年为员工提供不少于 40 小时的内部培训，培训费用由公司承担。
（检索 5.4 s / 生成 0.7 s）

DELETE /documents/13-员工培训管理制度.txt → 200，耗时 17.1 s
{"ok": true, "deleted": "13-员工培训管理制度.txt", "chunks": 47, "file_errors": [], "note": "检索器已重建"}

POST /ask（同一个问题，删除后）→ 200
依据：查阅资料中《03-请假管理制度》《12-员工行为规范》《05-薪酬福利制度》的全部条款，
     均未提及培训时长或培训小时数的相关规定。
结论：不知道。
（检索 5.3 s / 生成 1.6 s）

GET /health → documents: 12, chunks: 47, retriever_ready: true
```

要点：
- 上传后 `chunks` 47 → 48、`documents` 12 → 13，新内容**立刻可检索**（无需重启）
- 删除后 `chunks` 回到 47，再问同一问题变成"不知道" → **没有残留索引**
- 重建耗时 17 s（进程内 embedding 已加载，所以比首次构建的 60 s 快）
- `file_errors: []` 是"哪些文件没解析成功"的出口；解析失败不会静默丢文档
